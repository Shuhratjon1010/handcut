How to speed ramp and make smooth slow motion on iPhone

Short answer: Select a clip in HandCut and set its speed from 0.25× to 4×, or use the speed curve editor to add speed points for a ramp. For fluid slow motion from normal footage, slow the clip below 1× and turn on Smooth Slow-Mo (a Pro tool), which interpolates new frames.

Step by step

  1. Select the clip. Tap it on the timeline and open Speed.
  2. Constant speed. Drag between 0.25× and 4×.
  3. Speed ramp. Open the speed curve editor and Add speed points, for example fast-slow-fast around the key moment.
  4. Smooth Slow-Mo. With the clip below 1×, turn on Smooth Slow-Mo to generate in-between frames.
  5. Export. Tap Export Video.

When to use which

  • Constant speed: speed up a long process, slow down a single action.
  • Ramp: build tension into a reveal or a beat drop.
  • Smooth Slow-Mo: footage shot at 30 fps that you want slow without stutter. Footage shot in the iPhone's slow-motion mode already has extra frames.

Captions and speed

Generate captions after speed changes so word timings match. Speech at 0.25× or 4× is hard to understand, so mute or replace audio on heavily changed clips.

Questions people ask

Why is Smooth Slow-Mo greyed out?

Slow the clip below 1× first. HandCut says this if you try it at normal speed.

Is speed change free?

Speed control and ramps are part of the editor. Smooth Slow-Mo frame interpolation is Pro. For new users, exporting needs the monthly plan.
