How to turn a horizontal video vertical with Auto-Reframe

Short answer: Set the canvas to 9:16, then run Auto-Reframe (Pro). HandCut uses on-device person detection to move the crop so the speaker stays in frame through the clip, then you can fine-tune it.

Step by step

  1. Import the horizontal clip. A podcast, webinar or landscape talking-head recording works well.
  2. Choose 9:16 in Canvas. Open Canvas, pick 9:16.
  3. Run Auto-Reframe. Tap Auto-Reframe. It analyses the clip and keeps the person in frame on each clip it reframes.
  4. Check the result. Scrub through. If it chose the wrong person in a two-shot, reposition that part by hand.
  5. Caption and export. Generate captions after reframing so they sit on the final frame.

Where it works best

One main speaker, steady framing, decent light. Fast action and crowded frames are harder for any automatic reframing.

Privacy

The analysis uses Apple's Vision framework on the iPhone. The video isn't uploaded.

Troubleshooting

  • Reframe stopped or failed: HandCut reports it rather than leaving a bad crop. Trim very long clips into parts and run it on each.
  • Speaker drifts to the edge: re-run after trimming, or position that section by hand.
  • Soft image: a 1080p horizontal source cropped to vertical has fewer pixels. Record in 4K if you plan to reframe.

Questions people ask

Is Auto-Reframe free?

It's a Pro tool. New users get it in the monthly plan they need to export.

Does it work on two-person podcasts?

It follows a person. For conversations, split the clip and reframe each part on whoever is talking.
