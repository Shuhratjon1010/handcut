How to export an SRT caption file from iPhone

Short answer: Generate captions in HandCut, correct them, then tap Export .srt in the caption tray and share the file to Files, Mail or YouTube Studio. The file uses the same words and timing as your on-screen captions.

Step by step

  1. Generate captions. Import your video and tap Generate Captions.
  2. Proofread. Fix every word now. The SRT is plain text, so mistakes show in the CC track.
  3. Export the file. In the caption tray, tap Export .srt. The share sheet opens with the file.
  4. Save or send it. Save to Files, AirDrop it, or open YouTube Studio and add it under Subtitles.

Things to know

  • The button needs captions on the project. With none, HandCut tells you to add caption text or generate captions first.
  • An SRT export counts as an export, like a video export.
  • Export the SRT from the final edit. If you cut the video afterwards, the timing won't match.

Where SRT files are useful

YouTube, Vimeo, LinkedIn video, most course platforms (Teachable, Kajabi and similar) and video players that accept a caption track.

Troubleshooting

  • The share sheet shows nothing: the project has no caption text yet. Generate or type captions first.
  • YouTube says the file is invalid: make sure the file kept its .srt extension when saved.
  • Timing is off on upload: you edited the video after exporting the SRT. Export it again from the final cut.

Questions people ask

Can I export VTT instead?

HandCut writes SRT. Most platforms that take VTT also accept SRT, and free converters exist.

Does exporting the SRT need internet?

No. The file is written on your iPhone.
