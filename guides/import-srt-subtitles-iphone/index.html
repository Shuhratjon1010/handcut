How to add an SRT file to a video on iPhone

Short answer: Open the video in HandCut, go to the caption tray and tap Import .srt. The subtitle file's cues land on the timeline as captions you can restyle, move and edit, then Export Video burns them in.

Step by step

  1. Save the .srt to Files. AirDrop it, save it from email, or put it in iCloud Drive so the Files picker can see it.
  2. Open your video. Import the video the subtitles were made for with Add Video.
  3. Import. In the caption tray, tap Import .srt and pick the file.
  4. Check the sync. If the file was made for a different cut of the video, the timing will be off. Use the original edit.
  5. Style and export. Choose a look in Style and tap Export Video.

When importing beats generating

Import is the right choice when someone else produced the text: a professional transcript, a translation into a language your iPhone can't recognise on-device, or captions for a language other than English.

What an SRT file looks like

It's plain text: a number, a time range like 00:00:01,200 --> 00:00:03,900, and the line of text. Most transcription tools can export it.

Questions people ask

Is importing an SRT free?

Yes, importing a subtitle file is free in HandCut. For new users, exporting the finished video needs the monthly plan.

Can imported subtitles be word-by-word?

An SRT has timing per line, not per word, so word-by-word highlighting works best with captions HandCut generates itself.
