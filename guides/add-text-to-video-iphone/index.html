How to add text to a video on iPhone

Short answer: In HandCut, add a text overlay from the Text tray, type your words, choose a font (or import your own with Import Font), place it on the frame, and set how long it shows. Keyframes can move or scale it over time. For spoken words, generate captions instead of typing.

Step by step

  1. Add text. Open the Text tray and add a text overlay at the playhead.
  2. Type and style. Enter the text, pick a font and colour, and add emoji if you like.
  3. Place it. Drag it on the frame and resize it.
  4. Set timing. Drag the overlay's edges on the timeline.
  5. Animate. Use keyframes to move or scale it, or a text animation.

Text vs captions

Typed text is for titles, labels, lists and calls to action. Captions are for speech: Generate Captions writes and times them from the audio, which is far faster than typing what you said. A hook title sits between the two: it's taken from your first line but behaves like typed text.

Custom fonts

Import a font file you're licensed to use with Import Font. If HandCut says it could not import the font, check the file is a standard font file.

Images too

You can also place your own images, like a logo, on the picture and scale them.

Questions people ask

Can text follow a moving object?

Yes, with motion tracking (Pro), you can attach text to a tracked subject.

Will text appear in the SRT file?

No. Only captions go into the SRT, not text overlays.
